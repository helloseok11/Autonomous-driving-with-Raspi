## 학습

`YOLO.ipynb`를 Colab에서 열어 데이터셋을 준비한 뒤 필요한 학습 셀을 실행합니다. 데이터 다운로드 URL의 `<YOUR_ROBOFLOW_DOWNLOAD_URL>`은 본인 데이터셋의 URL로 교체합니다. 다운로드 키를 저장소에 기록하지 않습니다.

`DATA_YAML`의 기본값은 `/content/data.yaml`입니다. 이 YAML에 실제 학습·검증·테스트 경로와 클래스 이름을 설정해야 하며, 현재 저장소에는 원본 데이터와 YAML이 포함되어 있지 않습니다.

노트북은 `yolov8n.pt`, `yolo11n.pt`, `yolo26n.pt`의 실험 셀을 포함합니다. 각 셀은 30 epochs, 입력 크기 640, batch 16으로 학습하고 `test` 분할을 평가합니다. 현재 자료만으로 최종 모델이 어느 셀에서 생성되었는지는 단정하지 않습니다.

`yolo.py`는 세 실험을 순서대로 실행하는 노트북 내보내기 파일입니다. 실행 전 원하는 실험만 남기고 데이터 경로를 설정합니다. Colab 외부에서는 데이터 다운로드·압축 해제를 별도로 수행합니다. 의존성은 `ultralytics`이며, 지원 모델과 패키지 버전은 사용하는 학습 환경에서 확인합니다.

학습 코드·노트북의 다운로드 키를 플레이스홀더로 바꾸고 개인 Colab 링크·셀 메타데이터·실행 출력을 제거했습니다. PT 모델 파일은 원본을 그대로 복사했습니다. 이전 출력은 최종 모델 성능을 보장하지 않으므로 성능 수치를 인용하지 않았습니다.

## 웹캠 추론

저장소의 `training/` 폴더에서 실행합니다. `1_yolo_cam.py`와 `2_yolo_cam_fps.py`의 `YOLO(...)`를 아래와 같이 변경하면 최종 모델을 확인할 수 있습니다.

```python
model = YOLO('3_lec/best-신호등쪽 수정.pt')
```

```bash
cd training
python "3_lec/1_yolo_cam.py"
# 또는 FPS 표시 예제
python "3_lec/2_yolo_cam_fps.py"
```

웹캠 예제에는 `opencv-python`도 필요하며 `q` 키로 종료합니다. 원본 주석과 창 제목의 모델 버전 표기는 실제 PT 파일의 아키텍처를 검증한 결과가 아닙니다.
